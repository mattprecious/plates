# Plates
Plates is a simple Android app for calculating what weights to put on a barbell.

<img width="200" src="https://github.com/user-attachments/assets/6ca58532-dabd-42c1-96a6-9c932442a733" />

It was built to serve an immediate need and doesn't have any knobs to customize for more general
uses. Specifically, the barbell weight is hard-coded to 45lbs and the list of weights available are
the ones I currently own. Please open an issue if you are interested in any changes.

## Installation

The latest APK can be found as an artifact of a
[CI run](https://github.com/mattprecious/plates/actions). I have no plans to release this on the
Play Store.
